# Moonlight Cafe

A web page designed for a cafe, featuring a menu, interactive table reservation, feedback form, and a dark mode option.

##  Features

* **Interactive Menu:** Browse items categorized by Coffee, Desserts, Food, and Drinks with live price calculation.
* **Table Reservation:** Form to reserve indoor or outdoor seating with custom requests.
* **Customer Feedback:** Submit ratings and comments with live character counting.
* **Dark Mode:** Easily toggle between light and dark themes.
* **Responsive Design:** Clean layout optimized for both desktop and mobile views.

##  Built With

* HTML5
* CSS3
* JavaScript
